# Architecture

## Current data flow

```
Arabic Compose UI
      |
      v
TaskStore.addDraft(text)
      |
      v
normalizeTaskTitle(text)
      |
      v
App-private SharedPreferences (JSON array)
```

There is deliberately no network client and no device-action executor in this version.

## Modules

- `data/AgentTask.kt`: immutable draft model and input normalization.
- `data/TaskStore.kt`: local persistence of up to 100 text drafts.
- `ui/PhoneAgentTheme.kt`: product palette and dark Material theme.
- `ui/PhoneAgentApp.kt`: overview, task list, and truthful permission-status screens.
- `MainActivity.kt`: Android entry point.
- `.github/workflows/android-ci.yml`: unit tests, debug APK build, and artifact upload.

## Safety model

The current task state has exactly one value: `DRAFT`. It does not have `RUNNING`, `APPROVED`, or `EXECUTED` states because the current app has no execution engine.

Future device capabilities should be introduced behind an explicit capability interface. Each implementation must report its actual availability, explain its required permission, support cancellation, and produce an auditable result. A plan generated by an AI must be treated as untrusted input and never be passed straight to a shell or accessibility action.

## Build assumptions

- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Kotlin 2.2.21 with the matching Compose compiler plugin
- JDK 17
- Android SDK 36
- Minimum Android API 26

The hosted workflow builds a debug APK. A production/release APK is not signed by this repository; release signing should be added using user-controlled secrets only when needed.
