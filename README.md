# Phone Agent

**مساحة عمل عربية لإنجاز مهام الهاتف — بخطة واضحة، وصلاحيات تحت سيطرتك، ونتائج يمكن مراجعتها.**

Phone Agent تطبيق Android أصلي باستخدام Kotlin وJetpack Compose. الواجهة الأساسية حوار مع ثلاثة رفقاء، ومركز النشاط يحوّل الطلبات العملية إلى بطاقات محفوظة تتضمن خطة أولية وحالة وسجلًا زمنيًا.

## اتجاه المنتج

Phone Agent ليس مجرد محادثة مع أفاتار أو وعدًا بالتحكم الكامل. توجهنا هو جمع الحوار العربي، وتخطيط المهام، والموافقة الصريحة، وسجل التنفيذ والتحقق في تجربة واحدة. راجع [استراتيجية المنتج وتحليل المنافسين](docs/PRODUCT_STRATEGY.md) وخريطة البنية في [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## الموجود في الإصدار 0.2

- ثلاث شخصيات مرئية: **NOVA** للتخطيط، **ORION** للمهام التقنية، و**SENTINEL** لمراجعة الأمان.
- واجهة حوار عربية، اقتراحات سريعة، وسجل محادثة محلي مستقل لكل شخصية.
- التعرّف القائم على قواعد محلية على الطلبات العملية وحفظها كمهام.
- بطاقة مهمة تتضمن خطة تمهيدية من ثلاث خطوات، الحالة، وسجل أحداث مؤرخ.
- انتقالان فعليان ضمن سير المراجعة: مسودة ← تحتاج مراجعة/موافقة ← معتمدة وتنتظر محرك التنفيذ.
- لا يغيّر اعتماد الخطة أي شيء على الهاتف؛ الحالة النهائية توضّح أن محرك التنفيذ غير موصول.
- ترحيل تلقائي للمسودات المحفوظة في شكل الإصدار السابق عند فتح الإصدار الجديد.
- اختبارات وحدات لدورة المراجعة، وخطة الخطوات، وقواعد الحوار.

## حدود النسخة الحالية

- لا يوجد إذن `INTERNET` ولا اتصال بنموذج ذكاء اصطناعي.
- الردود قواعد محلية وليست نموذجًا لغويًا حقيقيًا.
- خطوات الخطة قائمة تحقق توضيحية وليست أوامر قابلة للتنفيذ.
- لا توجد خدمة Accessibility ولا منفّذ أوامر ولا إجراءات فعلية في الخلفية.
- الحالات مثل «قيد التنفيذ» و«مكتملة» محجوزة للمستقبل؛ لا تسمح الواجهة الحالية بكتابتها.
- تُحفظ المحادثات والمهام محليًا في مساحة التطبيق الخاصة.

## تنزيل APK

لا تثبّت ملفات Debug الناتجة عن التحقق في CI؛ فهي مخصّصة لاختبار البناء فقط ولا تُرفع كحزم توزيع مستقرة.

لإنشاء APK قابل للتحديث مستقبلًا، أعدّ مفتاح إصدار دائمًا وفق [دليل توقيع Android](docs/ANDROID_SIGNING.md)، ثم شغّل **Android CI** على main. سيُرفع **PhoneAgent-stable-release-apk** فقط بعد توقيعه والتحقق آليًا من أن بصمة شهادة APK تطابق شهادة المفتاح المضبوط.

إصدارات release تستخدم معرّف الحزمة io.phoneagent.mobile. نسخ Debug القديمة ذات اللاحقتين .debug أو .ci تطبيقات منفصلة ولن يتم استبدالها أو حذف بياناتها تلقائيًا.
